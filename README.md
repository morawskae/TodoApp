# TodoAPI

A full-stack task management application built with **ASP.NET Core Web API** and **React**.

The application allows users to register, log in, and manage their own to-do items, while administrators can manage users and access all tasks.

The project demonstrates RESTful API development, Entity Framework Core, SQLite, JWT authentication, role-based authorization, service-layer architecture, and a React/TypeScript frontend.
